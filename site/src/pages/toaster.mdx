# gli branch

Two subcommands. No friction.

## Create a Branch

Creates a new branch and pushes it to `origin` in one step. Upstream tracking is set automatically.

```bash
gli branch -c <name>
```

Example:

```bash
gli branch -c feature/auth
```

This runs `git checkout -b feature/auth` followed by `git push -u origin feature/auth`.

If the branch already exists, gli will let you know and won't overwrite it.

## Switch Branch

Switch to an existing branch.

```bash
gli branch -s <name>
```

Example:

```bash
gli branch -s main
```

The branch must already exist locally. Use `-c` to create new branches.
