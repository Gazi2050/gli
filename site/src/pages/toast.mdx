# gli commit

Stage all changes, generate an AI commit message, and push — all in one flow.

## Usage

```bash
gli commit
```

That's it. No flags, no arguments.

## How It Works

### 1. Stage

`gli commit` runs `git add .` automatically. All changes are staged.

### 2. AI Generation

The staged diff is sent to the [diny](https://diny.run/) API, which returns a commit message following [Conventional Commits](https://www.conventionalcommits.org/) format.

Messages always use one of: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, or `revert`.

### 3. Review

You see the generated message and pick an action:

| Option | What it does |
|---|---|
| **Commit & Push** | Accept the message, commit, and push |
| **Regenerate** | Ask the AI for a different message |
| **Edit** | Manually write your own message instead |
| **Cancel** | Abort and return to the terminal |

## Upstream

If your branch has no upstream set, gli will create one automatically and let you know.

## Skip Hooks

Pass `--no-verify` to bypass pre-commit and pre-push hooks:

```bash
gli commit --no-verify
```
