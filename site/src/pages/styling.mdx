# gli profile

Check any GitHub user's stats without leaving the terminal.

## Your Profile

View your own GitHub profile. gli detects your username from your git config (`user.name` or `github.user`).

```bash
gli me
```

## Any User

View any public GitHub profile by username.

```bash
gli profile <username>
```

Example:

```bash
gli profile torvalds
```

**Displays:**

- Name & Handle
- Bio
- Public Repos
- Followers / Following
- Location, Twitter, Blog
- Join Date
