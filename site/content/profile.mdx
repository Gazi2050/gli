# gli profile

View GitHub profiles from CLI.

## gli me

Show your GitHub profile.

```bash
gli me
```

Requires `github.user` configured:
```bash
git config --global github.user your-username
```

## gli profile

Show any user's profile.

```bash
gli profile octocat
gli profile torvalds
```

## Display

Shows:
- Name and @username
- Bio
- Stats: repos, followers, following
- Meta: location, Twitter, website, joined date
- Recent repos (top 5)

## Errors

- **No username** - Configure `github.user`
- **User not found** - Check username spelling
- **Rate limit** - Wait and retry
