# gli commit

AI-powered commit: stages all files, generates commit message, commits & pushes.

## Usage

```bash
gli commit [flags]
```

## Flags

| Flag | Description |
|------|-------------|
| `--no-verify` | Skip git hooks |

## Flow

1. **Staging** - Stages all files (`git add .`)
2. **AI** - Generates commit message
3. **Proposal** - Shows message with options
4. **Push** - Commits and pushes to remote

## Options

- **Commit and push** - Use generated message
- **Regenerate** - Get new AI message
- **Edit** - Modify message
- **Cancel** - Exit

## Keyboard

| Key | Action |
|-----|--------|
| ↑/↓ | Navigate |
| Enter | Confirm |
| q | Cancel |
| Esc | Back |
| Ctrl+C | Quit |

## Message Format

Uses Conventional Commits:
```
type: description
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`

Example: `feat: add login page`

## Errors

- **No staged changes** - Stage files first with `git add`
- **AI failed** - Check network, try Edit option
- **Push failed** - Check remote config
