# Getting Started

**gli** is a CLI tool that makes Git operations faster with AI-powered commits and GitHub integration.

## Install

Download from [releases](https://github.com/Gazi2050/gli/releases) or build from source:

```bash
git clone https://github.com/Gazi2050/gli.git
cd gli
go build -o gli ./cmd
sudo mv gli /usr/local/bin/
```

## Configure GitHub (optional)

```bash
git config --global github.user your-username
```

## Quick Commands

```bash
gli commit              # AI commit: stage + message + push
gli branch -c <name>    # Create branch
gli branch -s <name>    # Switch branch
gli me                  # Your GitHub profile
gli profile <user>      # Any GitHub profile
gli version             # Show version
```

## Commands

| Command | Description |
|---------|-------------|
| [commit](/docs/commit) | AI commit with staging & push |
| [branch](/docs/branch) | Create or switch branches |
| [profile](/docs/profile) | GitHub profiles |
| [version](/docs/version) | Show version |

## Requirements

- Git installed
- Network access (for AI commits & GitHub API)
- Git repo with remote origin
