# Installation

## Download

Get binary from [latest release](https://github.com/Gazi2050/gli/releases):

| OS | Download |
|---|----------|
| Linux x64 | `gli_Linux_x86_64` |
| Linux arm64 | `gli_Linux_arm64` |
| macOS x64 | `gli_Darwin_x86_64` |
| macOS arm64 | `gli_Darwin_arm64` |
| Windows | `gli_Windows_x86_64.exe` |

## Install

```bash
curl -L -o gli https://github.com/Gazi2050/gli/releases/latest/download/gli_Linux_x86_64
chmod +x gli
sudo mv gli /usr/local/bin/
```

## Build from Source

```bash
git clone https://github.com/Gazi2050/gli.git
cd gli
go build -o gli ./cmd
```

## Verify

```bash
gli version
```

## Configure GitHub

```bash
git config --global github.user your-username
```
