# gli branch

Create or switch branches.

## Create Branch

```bash
gli branch -c <name>
```

Creates branch and pushes to remote with upstream.

**Examples:**
```bash
gli branch -c feature/login
gli branch -c fix/bug-123
gli branch -c chore/update-deps
```

## Switch Branch

```bash
gli branch -s <name>
```

**Examples:**
```bash
gli branch -s main
gli branch -s develop
gli branch -s feature/login
```

## Errors

- **Empty name** - Provide branch name
- **Branch not found** - Create first or check spelling
- **Push failed** - Check remote config
